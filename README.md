# Python DS&A Practice (2022)

Data-structure and algorithm implementations written for practice — each file
is a standalone, runnable exercise.

**Algorithms:** binary search, bubble/insertion/merge/quick/selection sorts,
Dijkstra's shortest path, Euclid's GCD, prime sieves, Caesar cipher,
bitwise tricks (power-of-two, parity).

**Data structures:** binary trees, adjacency-list graphs, hash tables
(two-sum, character counts), linked structures.

Current interview practice lives in
[neetcode-submissions](https://github.com/brandopakel/neetcode-submissions).
